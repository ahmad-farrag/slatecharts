# Support

## Questions and bug reports

Open an issue on GitHub: [github.com/ahmad-farrag/SlateCharts/issues](https://github.com/ahmad-farrag/SlateCharts/issues)

Please include:

- Your Unreal Engine version and platform
- Which chart widget, and the data you gave it (a JSON string is ideal)
- What you expected and what happened, with a screenshot if it's visual
- For a crash, the call stack from the crash reporter or `Saved/Logs`
