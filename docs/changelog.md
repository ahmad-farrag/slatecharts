# Changelog

## SlateCharts 2.0

- Unreal Engine 5.8.
- `SlateCharts.PaintCache` console variable: set it to 0 to draw every chart without frame caching, to compare performance. Compiled out of Shipping.
- `SlateCharts.PaintCache.SameOutput` automation test: cached, replayed and immediate painting give Slate the same draw elements.

## SlateCharts Lite 1.0

- Bar, line and pie charts in one UMG widget, with a hover readout and a grow-in animation.
